# Inkloom AI – Intelligent Brand Governance Platform

## Overview
Inkloom AI is an AI-powered brand governance platform designed to help businesses maintain consistent, accurate, and trustworthy content.

It aims to analyse content against approved brand guidelines, identify potential issues, and provide explanations and improvement suggestions.

## Problem Statement
Businesses and content creators often struggle to maintain brand consistency and content quality. Manual checking can be time-consuming and may miss spelling mistakes, repeated information, incorrect claims, and tone inconsistencies.

Inkloom AI aims to make this review process smarter and more efficient.

## Current MVP Progress
- React-based frontend interface.
- Brand Guidelines input section.
- Content input section.
- Node.js and Express backend.
- API endpoint for receiving content and brand guidelines.
- Frontend and backend integration.

## Planned Features
- AI-powered content analysis.
- Spelling and grammar checking.
- Brand tone and terminology validation.
- Repeated and unnecessary content detection.
- Unsupported claim identification.
- AI-generated suggestions with explanations.
- Human review with accept/reject options.
- Final approved content generation.

## Technology Stack
- Frontend: React.js, JavaScript, Tailwind CSS
- Backend: Node.js, Express.js
- API: REST API
- Database: MongoDB (planned)
- AI Integration: LLM API (planned)
- Version Control: Git and GitHub

## Getting Started

### 1. Clone the repository
```bash
git clone YOUR_REPOSITORY_URL
```

### 2. Setup frontend
```bash
cd client
npm install
npm run dev
```

### 3. Setup backend
Open another terminal:
```bash
cd server
npm install
npm run dev
```

The frontend runs on the Vite development server and the backend runs on port 3000.
